### Added
- Safety checks to prevent extreme values (0.1 - 1.0 range)
- More detailed installation and configuration documentation

### Fixed

- Minor performance optimizations

### Changed
- Updated documentation and installation instructions

## [1.0.0] - 2026-07-24

### Added
- Initial release of TinyAtMidnight
- Player model shrinking to 35% of original size
- Mutual effect between all players who have the mod installed
- Configuration file with `ShrinkFactor` option
- Creepy "Tiny at Midnight" icon and branding
- Full package with README, manifest, and DLL
